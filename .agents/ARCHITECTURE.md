# Architecture

`@miquelt9/pc-ui` is presentational. Consumers own routing, focus traps, z-order, drag, print policy, and data. Shell pieces that already dismiss or portal are described in [chrome.md](./chrome.md), not reimplemented here.

## Layers

| Layer | Source | Role |
| --- | --- | --- |
| Tokens | `src/tokens.css` | `--pc-*` custom properties. Light, dark, and system themes. Catalog: [tokens.md](./tokens.md). |
| Primitives | `src/primitives.css` | `.pc-*` classes. Imports the tokens. |
| Bundle | `src/pc-ui.css` | Single file for a vanilla `<link>`. Generated by `scripts/bundle-css.mjs` from tokens + primitives. |
| React | `src/react/*.tsx`, barrel `src/index.ts` | Optional wrappers. Peer dependency on `react` and `react-dom` (both optional). |

`npm run build` bundles CSS and runs `tsc` into `dist/`. `prepare` and `prepublishOnly` call that build. `dist/` is gitignored.

## Exports

`package.json` `exports`:

| Export | Target |
| --- | --- |
| `.` | `dist/index.d.ts` (types) and `dist/index.js` (import) |
| `./pc-ui.css` | `src/pc-ui.css` |
| `./style.css` | `src/pc-ui.css` (alias) |
| `./tokens.css` | `src/tokens.css` |
| `./primitives.css` | `src/primitives.css` |

Published `files` are `dist` and `src`. `sideEffects` is CSS only.

Static sites copy or CDN-link `pc-ui.css` and use `.pc-*` classes. Bundled apps import the CSS and, if they want, the React components. The consumer checklist is in [AGENTS.md](../AGENTS.md).
